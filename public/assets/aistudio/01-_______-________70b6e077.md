# الملف الأول — التنظيف والأساس

أنت تنفذ أوامر فقط، ولا تبدع ولا تقترح.

## قواعد صارمة (تنطبق على الملفات الأربعة)

1. نفّذ الخطوات بالترتيب، واحدة واحدة، ولا تقفز.
2. كل ملف مكتوب كاملاً داخل كتلة كود: أنشئه أو استبدله **حرفياً** كما هو. لا تغيّر نصاً ولا ألواناً ولا أسماء.
3. لا تضف ميزات ولا مكتبات جديدة، ولا تلمس أي ملف غير مذكور.
4. لا تعدّل هذه الملفات أبداً: `vite.config.ts`، `tsconfig.json`، `.gitignore`، `.env.example`، `metadata.json`، `src/main.tsx`، `src/context/LightboxContext.tsx`، `src/components/Footer.tsx`، `src/components/Header.tsx` (إلا التعديل المذكور صراحة أدناه).
5. **متوقع** أن يظهر خطأ في البناء بين الملف الأول والملف الرابع، لأن الأقسام القديمة لم تُستبدل بعد. لا تحاول إصلاحه، ولا تشغّل أمر البناء إلا في آخر الملف الرابع.
6. بعد كل ملف اكتب للمستخدم ثلاثة أسطر فقط: ما أُنجز، وما لم يُنجز، وأي مشكلة.

## الخطوة 7: تعديلات صغيرة على ملفات موجودة

### 7.1 الملف `src/components/Header.tsx`

في وسم `<header` ابحث عن الكلمة `relative` داخل `className` الذي يبدأ بـ `shadow-nav relative z-50` واستبدلها بـ `sticky top-0`، بحيث يبدأ السطر هكذا:

```
className="shadow-nav sticky top-0 z-50 flex h-[77px] ...
```

(أبقِ باقي الأصناف كما هي.) لا تغيّر أي شيء آخر في الملف.

### 7.2 الملف `src/components/MosqueLogo.tsx`

- في النوع `variant?:` احذف `'vertical' |` و`'logotype'`، ليصبح: `variant?: 'horizontal' | 'icon';`
- احذف كتلة `if (variant === 'vertical') { ... }` كاملة من الدالة `getLogoPath`.

### 7.3 الملف `src/utils/prayerTimes.ts`

**السبب:** الحساب الحالي يستخدم ساعة جهاز الزائر، فيظهر خطأ في تمييز الصلاة القادمة لمن هو خارج توقيت دمشق. التعديل يثبّت التوقيت على دمشق.

أ) أضف هذه الدالة قبل `export function calculateDamascusPrayerTimes`:

```ts
function damascusNow(date: Date) {
  const parts = new Intl.DateTimeFormat('en-GB', {
    timeZone: 'Asia/Damascus',
    year: 'numeric',
    month: 'numeric',
    day: 'numeric',
    hour: 'numeric',
    minute: 'numeric',
    hour12: false,
  }).formatToParts(date);
  const get = (type: string) => Number(parts.find((p) => p.type === type)!.value);
  return {
    year: get('year'),
    month: get('month'),
    day: get('day'),
    minutes: (get('hour') % 24) * 60 + get('minute'),
  };
}
```

ب) داخل `calculateDamascusPrayerTimes` استبدل السطر:

```ts
  const jd = julianDay(date.getFullYear(), date.getMonth() + 1, date.getDate());
```

بالسطرين:

```ts
  const now = damascusNow(date);
  const jd = julianDay(now.year, now.month, now.day);
```

ج) استبدل السطر:

```ts
  const currentMinutesFromMidnight = date.getHours() * 60 + date.getMinutes() + date.getSeconds() / 60;
```

بالسطر:

```ts
  const currentMinutesFromMidnight = now.minutes;
```

د) داخل الدالة `getHijriDate` في كتلة `Intl.DateTimeFormat(locale, {` أضف `timeZone: 'Asia/Damascus',` كأول خاصية.
