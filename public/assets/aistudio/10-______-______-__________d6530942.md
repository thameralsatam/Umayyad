# الملف العاشر — الأرقام في الشاشة الأولى، ضبابية نافذة الصور، فراغ المعرض، وآداب الزيارة

نفّذ بعد التاسع. لا تعِد تشغيل أي ملف سابق.

## قواعد صارمة

1. نفّذ بالترتيب. انسخ حرفياً. لا إبداع ولا تغيير ولا إضافة.
2. في "استبدال نص": ابحث عن النص القديم بالضبط واستبدله. إذا لم تجده أو وجدته أكثر من مرة، توقف وأخبر المستخدم ولا تخمّن.
3. لا لون خارج قائمة الهوية: `#002623` و`#003D30` و`#B9A779` و`#FFFFFF` و`#EBEBEB` و`#F5F5F5` و`#637381` وما يشتق منها بالشفافية.
4. لا وضع داكن. لا تلمس `Header.tsx` ولا `Footer.tsx`.
5. في النهاية فقط: `npm run lint` ثم `npm run build`.
6. تقرير من خمسة أسطر كحد أقصى.

## الخطوة 3: `src/components/HeroSection.tsx` (استبدال كامل)

الشاشة الأولى صارت أغنى: وسم صغير، العنوان، الوصف، الأرقام الثلاثة، زر التمرير. تحتها الصورة ثم المواقيت.

```tsx
import React, { useRef } from 'react';
import { motion, useReducedMotion, useScroll, useTransform } from 'motion/react';
import { ChevronDown } from 'lucide-react';
import { Language, LightboxImageItem } from '../types';
import { GATES, HISTORY, HOME } from '../data/content';
import { imgAlt, imgSrc } from '../data/images';
import { useLightbox } from '../context/LightboxContext';
import { PrayerWidget } from './PrayerWidget';
import { CountUp, ParallaxImage, Reveal } from './Motion';

interface HeroSectionProps {
  lang: Language;
}

const STATS = [
  { value: HISTORY.length, label: { ar: 'حقب تاريخية', en: 'Historical eras' } },
  { value: 3, label: { ar: 'مآذن', en: 'Minarets' } },
  { value: GATES.length, label: { ar: 'مداخل', en: 'Entrances' } },
];

export const HeroSection: React.FC<HeroSectionProps> = React.memo(({ lang }) => {
  const isAr = lang === 'ar';
  const lines = HOME.title[lang];
  const firstScreen = useRef<HTMLDivElement>(null);
  const reduce = useReducedMotion();
  const { openLightbox } = useLightbox();

  const { scrollYProgress } = useScroll({ target: firstScreen, offset: ['start start', 'end start'] });
  const textY = useTransform(scrollYProgress, [0, 0.7], ['0%', '18%']);
  const textOpacity = useTransform(scrollYProgress, [0, 0.6], [1, 0]);

  const goNext = () => {
    document.getElementById('history')?.scrollIntoView({ behavior: 'smooth', block: 'start' });
  };

  const slides: LightboxImageItem[] = [{ src: imgSrc('hero'), title: imgAlt('hero', lang) }];

  return (
    <section id="home" aria-labelledby="hero-title" className="relative overflow-hidden bg-white">
      <div
        aria-hidden="true"
        className="pointer-events-none absolute -top-24 left-1/2 h-72 w-72 -translate-x-1/2 rounded-full bg-gold/20 blur-3xl sm:h-[28rem] sm:w-[28rem]"
      />

      <div
        ref={firstScreen}
        className="relative mx-auto flex min-h-[calc(100svh-77px)] max-w-6xl flex-col items-center justify-center px-5 py-16 text-center sm:px-8"
      >
        <motion.div
          style={reduce ? undefined : { y: textY, opacity: textOpacity }}
          className="flex w-full flex-col items-center"
        >
          <Reveal immediate className="mb-8">
            <span className="pill tint-gold border-gold/50 text-gold-deep">
              {isAr ? 'وزارة الأوقاف' : 'Ministry of Endowments'}
            </span>
          </Reveal>

          <Reveal immediate delay={0.06}>
            <h1 id="hero-title" className="hero-title">
              <span className="block text-gold">{lines[0]}</span>
              <span className="block">{lines[1]}</span>
            </h1>
          </Reveal>

          <Reveal immediate delay={0.14}>
            <p className="lead mx-auto mt-8 max-w-2xl">{HOME.lead[lang]}</p>
          </Reveal>

          <Reveal immediate delay={0.22} className="mt-12 w-full">
            <ul className="mx-auto flex max-w-xl items-stretch justify-center">
              {STATS.map((s, i) => (
                <li key={i} className={`flex-1 px-3 ${i > 0 ? 'border-s border-gold/50' : ''}`}>
                  <div className="text-4xl font-light text-ink sm:text-5xl">
                    <CountUp value={s.value} />
                  </div>
                  <p className="mt-1 text-sm text-ink-soft sm:text-base">{s.label[lang]}</p>
                </li>
              ))}
            </ul>
          </Reveal>

          <motion.button
            type="button"
            onClick={goNext}
            aria-label={isAr ? 'انتقل إلى القسم التالي' : 'Go to the next section'}
            initial={{ opacity: 0, y: 10 }}
            animate={reduce ? { opacity: 1, y: 0 } : { opacity: 1, y: [0, 8, 0] }}
            transition={{
              opacity: { delay: 0.8, duration: 0.8 },
              y: { repeat: Infinity, duration: 2.4, ease: 'easeInOut' },
            }}
            className="pill tint-cream mt-12 cursor-pointer text-ink-soft transition-colors hover:border-gold"
          >
            <span>{isAr ? 'تابع التمرير' : 'Scroll to explore'}</span>
            <ChevronDown className="h-4 w-4" strokeWidth={1.5} aria-hidden="true" />
          </motion.button>
        </motion.div>
      </div>

      <div className="relative mx-auto max-w-6xl px-5 pb-24 pt-4 sm:px-8 sm:pb-32">
        <Reveal>
          <div className="relative">
            <button
              type="button"
              onClick={() => openLightbox(slides, 0)}
              aria-label={isAr ? 'تكبير الصورة' : 'Enlarge image'}
              className="block w-full cursor-zoom-in"
            >
              <ParallaxImage
                src={imgSrc('hero')}
                alt={imgAlt('hero', lang)}
                lang={lang}
                className="h-[56svh] min-h-[320px] w-full rounded-[2.5rem] bg-[#ebebeb] shadow-[0_24px_60px_-30px_rgba(0,38,35,0.18)] sm:h-[66svh]"
              />
            </button>
            <span className="pointer-events-none absolute start-5 top-5 max-w-[85%] truncate rounded-full border border-white/30 bg-ink/45 px-4 py-2 text-sm text-white backdrop-blur-md">
              {imgAlt('hero', lang)}
            </span>
          </div>
        </Reveal>

        <Reveal className="mt-6 sm:mt-8">
          <PrayerWidget lang={lang} />
        </Reveal>
      </div>
    </section>
  );
});
```

## الخطوة 4: `src/components/VisitSection.tsx` (استبدال كامل)

آداب الزيارة: بطاقة واحدة بلون واحد، فيها أربعة صفوف بأيقونات دائرية بدل البطاقات الملونة.

```tsx
import React, { useState } from 'react';
import { Camera, Footprints, Shirt, VolumeX } from 'lucide-react';
import { Language } from '../types';
import { CONDUCT, GATES, HOURS, SECTIONS, VISIT_LABELS } from '../data/content';
import { AccordionRow } from './AccordionRow';
import { Reveal } from './Motion';
import { SectionHead } from './SectionHead';

interface VisitSectionProps {
  lang: Language;
}

const CONDUCT_ICONS: Record<string, React.ComponentType<{ className?: string; strokeWidth?: number }>> = {
  dress: Shirt,
  shoes: Footprints,
  quiet: VolumeX,
  photo: Camera,
};

export const VisitSection: React.FC<VisitSectionProps> = React.memo(({ lang }) => {
  const isAr = lang === 'ar';
  const [openId, setOpenId] = useState<string | null>(null);

  return (
    <section id="visit" aria-labelledby="visit-heading" className="bg-ivory px-5 py-24 sm:px-8 sm:py-32">
      <div className="mx-auto max-w-6xl">
        <SectionHead
          id="visit-heading"
          no="05"
          title={SECTIONS.visit.title[lang]}
          lead={SECTIONS.visit.lead[lang]}
          isAr={isAr}
        />

        <h3 className="sr-only">{VISIT_LABELS.gates[lang]}</h3>
        <div className="space-y-4">
          {GATES.map((g) => (
            <Reveal key={g.id}>
              <AccordionRow
                id={`gate-${g.id}`}
                eyebrow={g.direction[lang]}
                title={g.name[lang]}
                summary={g.summary[lang]}
                open={openId === g.id}
                onToggle={() => setOpenId(openId === g.id ? null : g.id)}
              >
                <p className="lead max-w-2xl">{g.more[lang]}</p>
              </AccordionRow>
            </Reveal>
          ))}
        </div>

        <div className="mt-20 sm:mt-24">
          <Reveal>
            <h3 className="row-title mb-8">{VISIT_LABELS.conduct[lang]}</h3>
          </Reveal>
          <Reveal>
            <ul className="card-soft grid sm:grid-cols-2">
              {CONDUCT.map((c, i) => {
                const Icon = CONDUCT_ICONS[c.id] ?? Shirt;
                return (
                  <li
                    key={c.id}
                    className={`flex items-start gap-5 p-6 sm:p-8 ${i > 0 ? 'border-t border-line' : ''} ${
                      i === 1 ? 'sm:border-t-0' : ''
                    } ${i % 2 === 1 ? 'sm:border-s sm:border-line' : ''}`}
                  >
                    <span className="grid h-12 w-12 shrink-0 place-items-center rounded-full border border-gold/60 text-ink">
                      <Icon className="h-5 w-5" strokeWidth={1.5} />
                    </span>
                    <div>
                      <h4 className="text-lg font-medium text-ink">{c.title[lang]}</h4>
                      <p className="mt-1 text-base font-light leading-8 text-ink-soft">{c.text[lang]}</p>
                    </div>
                  </li>
                );
              })}
            </ul>
          </Reveal>
        </div>

        <Reveal className="mt-10 sm:mt-14">
          <div className="card-soft flex flex-col gap-4 p-6 sm:flex-row sm:items-center sm:gap-8 sm:p-8">
            <span className="pill tint-gold w-fit border-gold/50 text-gold-deep">{VISIT_LABELS.hours[lang]}</span>
            <p className="lead">{HOURS[lang]}</p>
          </div>
        </Reveal>
      </div>
    </section>
  );
});
```

## الخطوة 5: الفحص النهائي

1. `npm run lint` ثم `npm run build`، وأصلح الأخطاء بأقل تعديل. إذا لم يوجد أحد الرموز (`Footprints` أو `VolumeX` أو `Shirt` أو `Camera`) في نسخة `lucide-react` المثبتة، استبدله بأقرب رمز موجود واذكر ذلك.
2. أجب بـ "نعم" أو "لا" بعد التحقق الفعلي:
   - الشاشة الأولى فيها: الوسم، العنوان، الوصف، الأرقام الثلاثة، زر التمرير
   - بعد الشاشة الأولى: الصورة ثم المواقيت
   - خلفية نافذة الصور ضبابية وليست خضراء كثيفة
   - في المعرض فراغ عند بداية الشريط ونهايته
   - آداب الزيارة في بطاقة واحدة بلون واحد مع أيقونات
3. تقرير من خمسة أسطر كحد أقصى.
