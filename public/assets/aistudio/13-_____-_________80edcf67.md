# الملف الثالث عشر — ترتيب ترويسة الأقسام وتوسيط الرقم

نفّذ بعد الثاني عشر. استبدل ملفاً واحداً فقط.

## قواعد صارمة

1. انسخ الكود حرفياً. لا إبداع ولا تغيير ولا إضافة. لا تلمس أي ملف آخر.
2. كل النصوص والأرقام بخط قمرة. ممنوع تحديد أي خط نظام.
3. في النهاية فقط: `npm run lint` ثم `npm run build`، وأصلح الأخطاء بأقل تعديل.
4. تقرير من ثلاثة أسطر كحد أقصى.

## `src/components/SectionHead.tsx` (استبدال كامل)

الترتيب: العنوان أولاً، ثم تحته صف فيه الدائرة (الرقم) والخط الذهبي، ثم الوصف.

الرقم داخل الدائرة مُزاح بمقدار مقاس من الخط نفسه (الأرقام في قمرة تقع أعلى مركزها بنحو 0.13 من حجم الخط وأيمن قليلاً بنحو 0.05)، فيظهر في المنتصف البصري تماماً.

```tsx
import React from 'react';
import { GoldRule, Reveal } from './Motion';

interface SectionHeadProps {
  id: string;
  no: string;
  title: string;
  lead?: string;
  isAr: boolean;
}

const toArabicDigits = (s: string) => s.replace(/\d/g, (d) => '٠١٢٣٤٥٦٧٨٩'[Number(d)]);

export const SectionHead: React.FC<SectionHeadProps> = ({ id, no, title, lead, isAr }) => (
  <header className="mb-12 sm:mb-16">
    <Reveal>
      <h2 id={id} className="display-title">
        {title}
      </h2>
    </Reveal>

    <Reveal delay={0.08}>
      <div className="mt-6 flex items-center gap-5">
        <span
          aria-hidden="true"
          className="grid h-12 w-12 shrink-0 place-items-center rounded-full border border-gold/70 text-lg font-light leading-none text-ink"
        >
          <span className="block -translate-x-[0.05em] translate-y-[0.13em]">{isAr ? toArabicDigits(no) : no}</span>
        </span>
        <GoldRule isAr={isAr} className="w-24 sm:w-44" />
      </div>
    </Reveal>

    {lead && (
      <Reveal delay={0.14}>
        <p className="lead mt-6 max-w-2xl">{lead}</p>
      </Reveal>
    )}
  </header>
);
```

## الفحص

1. `npm run lint` ثم `npm run build`.
2. أجب بـ "نعم" أو "لا": العنوان فوق، ثم الدائرة والخط تحته، ثم الوصف. الرقم داخل `<span>` داخلي عليه الإزاحة.
3. تقرير من ثلاثة أسطر كحد أقصى.
