# الملف الثاني عشر — المسافة الأخيرة في المعرض، ترويسة الأقسام الجديدة، وتزامن نافذة الصور

نفّذ بعد الحادي عشر. لا تعِد تشغيل أي ملف سابق.

## قواعد صارمة

1. نفّذ بالترتيب. انسخ حرفياً. لا إبداع ولا تغيير ولا إضافة.
2. في "استبدال نص": ابحث عن النص القديم بالضبط واستبدله. إذا لم تجده أو وجدته أكثر من مرة، توقف وأخبر المستخدم ولا تخمّن.
3. لا لون خارج قائمة الهوية: `#002623` و`#003D30` و`#B9A779` و`#FFFFFF` و`#EBEBEB` و`#F5F5F5` و`#637381` وما يشتق منها بالشفافية.
4. كل النصوص والأرقام بخط قمرة. ممنوع تحديد أي خط نظام (`system-ui` أو `sans-serif` كخط مباشر) في أي مكوّن.
5. لا وضع داكن. لا تلمس `Header.tsx` ولا `Footer.tsx`.
6. في النهاية فقط: `npm run lint` ثم `npm run build`.
7. تقرير من خمسة أسطر كحد أقصى.

## الخطوة 2: `src/components/SectionHead.tsx` (استبدال كامل)

ترويسة هادئة وفخمة: دائرة صغيرة بحد ذهبي فيها الرقم بخط قمرة، يتبعها خط ذهبي رفيع يمتد عند الظهور، ثم العنوان. لا أرقام ضخمة خلفية.

```tsx
import React from 'react';
import { GoldRule, Reveal } from './Motion';

interface SectionHeadProps {
  id: string;
  no: string;
  title: string;
  lead?: string;
  isAr: boolean;
}

const toArabicDigits = (s: string) => s.replace(/\d/g, (d) => '٠١٢٣٤٥٦٧٨٩'[Number(d)]);

export const SectionHead: React.FC<SectionHeadProps> = ({ id, no, title, lead, isAr }) => (
  <header className="mb-12 sm:mb-16">
    <Reveal>
      <div className="flex items-center gap-5">
        <span
          aria-hidden="true"
          className="grid h-12 w-12 shrink-0 place-items-center rounded-full border border-gold/70 text-lg font-light text-ink"
        >
          {isAr ? toArabicDigits(no) : no}
        </span>
        <GoldRule isAr={isAr} className="w-24 sm:w-44" />
      </div>
    </Reveal>

    <Reveal delay={0.05}>
      <h2 id={id} className="display-title mt-7">
        {title}
      </h2>
    </Reveal>

    {lead && (
      <Reveal delay={0.1}>
        <p className="lead mt-6 max-w-2xl">{lead}</p>
      </Reveal>
    )}
  </header>
);
```

## الخطوة 3: `src/components/UniversalLightbox.tsx` (استبدالات نصية)

الانتقال بين الصور أسرع، والوصف تحت الصورة يتبدل بنفس التوقيت تماماً (خروج سريع 0.2 ثانية ثم دخول 0.35 ثانية، للصورة والوصف معاً).

**3.1** ابحث عن: `enter: (d: number) => ({ opacity: 0, x: d * 56, scale: 0.98 }),`
استبدل بـ: `enter: (d: number) => ({ opacity: 0, x: d * 32 }),`

**3.2** ابحث عن: `center: { opacity: 1, x: 0, scale: 1 },`
استبدل بـ: `center: { opacity: 1, x: 0, transition: { duration: 0.35, ease: 'easeOut' } },`

**3.3** ابحث عن: `exit: (d: number) => ({ opacity: 0, x: -d * 56, scale: 0.98 }),`
استبدل بـ: `exit: (d: number) => ({ opacity: 0, x: -d * 32, transition: { duration: 0.2, ease: 'easeIn' } }),`

**3.4** احذف هذا السطر بالكامل (داخل وسم الصورة):
```
                transition={{ duration: 0.45, ease: [0.22, 1, 0.36, 1] }}
```

**3.5** ابحث عن:
```
        <motion.div
          key={currentIndex}
          initial={{ opacity: 0, y: 10 }}
          animate={{ opacity: 1, y: 0 }}
          transition={{ duration: 0.5, delay: 0.15, ease: [0.22, 1, 0.36, 1] }}
          className="max-w-2xl rounded-3xl border border-white/15 bg-white/10 px-6 py-4 text-center backdrop-blur-md"
        >
          <h3 className="text-lg font-light sm:text-xl">{item.title}</h3>
          {item.caption && <p className="mt-1 text-sm font-light text-white/70">{item.caption}</p>}
        </motion.div>
```
استبدل بـ:
```
        <AnimatePresence mode="wait" initial={false}>
          <motion.div
            key={currentIndex}
            initial={{ opacity: 0, y: 8 }}
            animate={{ opacity: 1, y: 0, transition: { duration: 0.35, ease: 'easeOut' } }}
            exit={{ opacity: 0, y: -6, transition: { duration: 0.2, ease: 'easeIn' } }}
            className="max-w-2xl rounded-3xl border border-white/15 bg-white/10 px-6 py-4 text-center backdrop-blur-md"
          >
            <h3 className="text-lg font-light sm:text-xl">{item.title}</h3>
            {item.caption && <p className="mt-1 text-sm font-light text-white/70">{item.caption}</p>}
          </motion.div>
        </AnimatePresence>
```

## الخطوة 4: الفحص النهائي

1. `npm run lint` ثم `npm run build`، وأصلح الأخطاء بأقل تعديل دون تغيير التصميم.
2. ابحث في `src/components/` (عدا `Header.tsx` و`Footer.tsx`) عن `system-ui` أو `font-family` أو `font-sans` أو `font-mono`. لا تغيّر شيئاً، فقط اذكر ما وجدته.
3. أجب بـ "نعم" أو "لا" بعد التحقق الفعلي:
   - لا عنصر إضافي بعد آخر صورة في المعرض
   - ترويسة كل قسم: دائرة فيها الرقم + خط ذهبي، ولا رقم ضخم خلفي
   - لا يوجد أي خط نظام في الأرقام
   - الصورة والوصف في نافذة العرض يتبدلان بنفس التوقيت
4. تقرير من خمسة أسطر كحد أقصى.
