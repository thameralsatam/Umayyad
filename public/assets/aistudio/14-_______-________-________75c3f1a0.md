# الملف الرابع عشر — تصحيحات المراجعة الأخيرة

نفّذ بعد الملفات السابقة. كلها استبدالات نصية صغيرة، لا تعدّل شيئاً غيرها.

## قواعد صارمة

1. انسخ حرفياً. لا إبداع ولا تغيير ولا إضافة.
2. في كل استبدال: ابحث عن النص القديم بالضبط. إذا لم تجده أو وجدته أكثر من مرة، توقف وأخبر المستخدم ولا تخمّن.
3. لا تلمس أي ملف غير مذكور.
4. في النهاية فقط: `npm run lint` ثم `npm run build`.
5. تقرير من ثلاثة أسطر كحد أقصى.

```
export function damascusNow(): Date {
  const now = new Date();
```
استبدل بـ:
```
export function damascusNow(): Date {
  return damascusWall(new Date());
}

export function damascusWall(now: Date): Date {
```

**1.2** ابحث عن:
```
  const jd = julianDay(date.getFullYear(), date.getMonth() + 1, date.getDate());
  const d = jd - 2451545.0;
```
استبدل بـ:
```
  const wall = damascusWall(date);
  const jd = julianDay(wall.getFullYear(), wall.getMonth() + 1, wall.getDate());
  const d = jd - 2451545.0;
```

**1.3** ابحث عن:
`const currentMinutesFromMidnight = date.getHours() * 60 + date.getMinutes() + date.getSeconds() / 60;`
استبدل بـ:
`const currentMinutesFromMidnight = wall.getHours() * 60 + wall.getMinutes() + wall.getSeconds() / 60;`

استبدل **الاثنتين** بـ:
`تعريف بالجامع الأموي الكبير في دمشق: تاريخه وعمارته وفسيفساؤه ودليل زيارته.`

## الخطوة 4: الفحص النهائي

1. `npm run lint` ثم `npm run build`.
2. أجب بـ "نعم" أو "لا":
   - لا يوجد في `index.html` أي ذكر لـ "السجلات الأثرية"
   - لا يوجد في `content.ts` ذكر لـ "النوفرة" ولا "حرفيي بلاد الشام" ولا "النموذج التأسيسي"
   - `calculateDamascusPrayerTimes` تستخدم `wall` لحساب اليوم والدقائق الحالية
3. تقرير من ثلاثة أسطر كحد أقصى.
