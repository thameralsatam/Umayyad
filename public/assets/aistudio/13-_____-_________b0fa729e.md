# الملف الثالث عشر (النسخة الثالثة) — ترويسة الأقسام

استبدل ملفاً واحداً فقط. الاستبدال كامل، فلا يهم إن نُفّذت نسخة سابقة من هذا الملف.

## قواعد صارمة

1. انسخ الكود حرفياً. لا إبداع ولا تغيير ولا إضافة. لا تلمس أي ملف آخر.
2. كل النصوص والأرقام بخط قمرة. ممنوع تحديد أي خط نظام.
3. في النهاية فقط: `npm run lint` ثم `npm run build`، وأصلح الأخطاء بأقل تعديل.
4. تقرير من ثلاثة أسطر كحد أقصى.

## `src/components/SectionHead.tsx` (استبدال كامل)

الشكل: الرقم (بلا دائرة، ذهبي صغير) بجانب العنوان في نفس السطر على خط الأساس. تحتهما خط ذهبي قصير بطول ثابت (5 وحدات) لكل العناوين، يبدأ من حافة المحتوى نفسها فيتوازى مع الوصف تحته.

```tsx
import React from 'react';
import { GoldRule, Reveal } from './Motion';

interface SectionHeadProps {
  id: string;
  no: string;
  title: string;
  lead?: string;
  isAr: boolean;
}

const toArabicDigits = (s: string) => s.replace(/\d/g, (d) => '٠١٢٣٤٥٦٧٨٩'[Number(d)]);

export const SectionHead: React.FC<SectionHeadProps> = ({ id, no, title, lead, isAr }) => (
  <header className="mb-12 sm:mb-16">
    <Reveal>
      <div className="flex items-baseline gap-3 sm:gap-4">
        <span aria-hidden="true" className="shrink-0 text-xl font-medium text-gold sm:text-3xl">
          {isAr ? toArabicDigits(no) : no}
        </span>
        <h2 id={id} className="display-title">
          {title}
        </h2>
      </div>
    </Reveal>

    <GoldRule isAr={isAr} className="mt-5 w-20" />

    {lead && (
      <Reveal delay={0.1}>
        <p className="lead mt-6 max-w-2xl">{lead}</p>
      </Reveal>
    )}
  </header>
);
```

## الفحص

1. `npm run lint` ثم `npm run build`.
2. أجب بـ "نعم" أو "لا": الرقم بجانب العنوان بلا دائرة، والخط الذهبي تحتهما بطول ثابت `w-20` ولا يتبع طول العنوان، والوصف يبدأ من نفس الحافة.
3. تقرير من ثلاثة أسطر كحد أقصى.
