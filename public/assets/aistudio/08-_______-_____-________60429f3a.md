# الملف الثامن — الألوان، ميزات الخط، إصلاح صور المعرض، وحذف الصور غير المربوطة

نفّذ بعد السابع. لا تعِد تشغيل أي ملف سابق.

## قواعد صارمة

1. نفّذ بالترتيب. انسخ حرفياً. لا إبداع ولا تغيير ولا إضافة.
2. في "استبدال نص": ابحث عن النص القديم بالضبط واستبدله. إذا لم تجده أو وجدته أكثر من مرة، توقف وأخبر المستخدم ولا تخمّن.
3. لا تعدّل أي ملف غير مذكور. لا وضع داكن.
4. في النهاية فقط: `npm run lint` ثم `npm run build`.
5. تقرير من خمسة أسطر كحد أقصى.

## الخطوة 1: `src/index.css` (استبدالات نصية)

الألوان تُشتق الآن من لوني الهوية فقط (الأخضر `#002623` والذهبي `#b9a779`) بشفافية، مع الكريمي `#f4efe6` الموجود أصلاً في الموقع القديم. تُحذف درجات النعناع المضافة.

**1.1** استبدل:
`background-image: linear-gradient(135deg, #f5ebd7 0%, #e6d8b0 100%);`
بـ:
`background-image: linear-gradient(135deg, rgba(185, 167, 121, 0.28) 0%, rgba(185, 167, 121, 0.1) 100%);`

**1.2** استبدل:
`background-image: linear-gradient(135deg, #e8f0ed 0%, #cddfd8 100%);`
بـ:
`background-image: linear-gradient(135deg, rgba(0, 61, 48, 0.12) 0%, rgba(0, 38, 35, 0.04) 100%);`

**1.3** استبدل `--color-ink-soft: #3f4b49;` بـ `--color-ink-soft: #524e47;`

**1.4** استبدل `  color: #3f4b49;` بـ `  color: #524e47;`

## الخطوة 2: ميزات خط قمرة (OpenType)

فحصت الخط فعلياً. الميزات الموجودة فيه: `liga` و`dlig` و`rlig` و`ccmp` و`kern` و`mark` و`mkmk` و`salt` و`ss01` و`ss02` و`ss04`.
- نفعّل في كل الموقع: `liga` و`dlig` و`rlig` و`ccmp` و`calt` و`kern` و`mark` و`mkmk`.
- نفعّل `ss01` في العناوين الكبيرة فقط (تمديد خطي جميل للحروف).
- لا نفعّل `ss02` أبداً: يحوّل الياء إلى شكل يشبه الهمزة ("في" تصير "فئ").
- لا نفعّل `salt` ولا `ss04` في النص العادي: `salt` يمدّ الحروف ويكسر الأسطر، و`ss04` يغيّر شكل الياء الأخيرة بشكل غير منتظم.

**2.1** استبدل:
`    font-feature-settings: "liga" 1, "calt" 1, "kern" 1;`
بـ:
```
    font-feature-settings: "liga" 1, "dlig" 1, "rlig" 1, "calt" 1, "ccmp" 1, "kern" 1, "mark" 1, "mkmk" 1;
    font-variant-ligatures: common-ligatures discretionary-ligatures contextual;
    font-kerning: normal;
    text-rendering: optimizeLegibility;
```

**2.2** استبدل:
```
  line-height: 1.12;
  letter-spacing: -0.015em;
```
بـ:
```
  line-height: 1.12;
  letter-spacing: -0.015em;
  font-feature-settings: "liga" 1, "dlig" 1, "rlig" 1, "calt" 1, "ccmp" 1, "kern" 1, "mark" 1, "mkmk" 1, "ss01" 1;
```

**2.3** استبدل:
```
  line-height: 1.15;
  letter-spacing: -0.01em;
```
بـ:
```
  line-height: 1.15;
  letter-spacing: -0.01em;
  font-feature-settings: "liga" 1, "dlig" 1, "rlig" 1, "calt" 1, "ccmp" 1, "kern" 1, "mark" 1, "mkmk" 1, "ss01" 1;
```

## الخطوة 4: حذف الصور غير المربوطة

1. اعرض قائمة كل الملفات داخل `public/images/`.
2. لكل ملف: ابحث عن اسمه الكامل (مع الامتداد) في `src/` و`index.html` و`metadata.json` و`package.json` وأي ملف نصي داخل `public/` خارج `public/images/`.
3. الملف الذي لا يظهر اسمه في أي مكان من هذه (وليس واحداً من ملفات `src/data/images.ts`) احذفه.
4. لا تحذف شيئاً من `public/fonts/` ولا `public/logo/` ولا أي ملف خارج `public/images/`.
5. أخبر المستخدم بقائمة بما حذفته (الاسم فقط)، وبقائمة الصور المسجّلة في `images.ts` التي لا يوجد لها ملف فعلي في `public/images/` إن وُجدت.

## الخطوة 5: الفحص النهائي

1. `npm run lint` ثم `npm run build`، وأصلح الأخطاء بأقل تعديل.
2. أجب بـ "نعم" أو "لا" بعد التحقق الفعلي:
   - لا يوجد في `index.css` أي لون خارج: `#002623` و`#003d30` و`#b9a779` و`#7d6b38` و`#524e47` و`#f4efe6` و`#faf8f5` و`#ffffff` وما يشتق منها بالشفافية
   - لا يوجد `ss02` في أي مكان
   - كل صور المعرض ظاهرة داخل الإطار
   - لا توجد صورة في `public/images/` غير مستخدمة
3. تقرير من خمسة أسطر كحد أقصى.
