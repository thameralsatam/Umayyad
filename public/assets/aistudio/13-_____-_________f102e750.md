# الملف الثالث عشر (نسخة محدّثة) — ترتيب ترويسة الأقسام وتوسيط الرقم

استبدل ملفاً واحداً فقط. إذا نفّذت النسخة القديمة من هذا الملف فلا بأس، الاستبدال كامل.

## قواعد صارمة

1. انسخ الكود حرفياً. لا إبداع ولا تغيير ولا إضافة. لا تلمس أي ملف آخر.
2. كل النصوص والأرقام بخط قمرة. ممنوع تحديد أي خط نظام.
3. في النهاية فقط: `npm run lint` ثم `npm run build`، وأصلح الأخطاء بأقل تعديل.
4. تقرير من ثلاثة أسطر كحد أقصى.

## `src/components/SectionHead.tsx` (استبدال كامل)

الشكل المطلوب: الدائرة (فيها الرقم) بجانب العنوان في نفس السطر، والخط الذهبي تحت العنوان مباشرة بعرضه وبدايته، ثم الوصف.

مثال: `(٠٣) الفسيفساء` والخط الذهبي تحت كلمة "الفسيفساء".

الرقم داخل الدائرة مُزاح بمقدار مقاس من خط قمرة (يقع أعلى مركزه بنحو 0.13 من حجم الخط وأيمن قليلاً بنحو 0.05) فيظهر في المنتصف البصري تماماً.

```tsx
import React from 'react';
import { GoldRule, Reveal } from './Motion';

interface SectionHeadProps {
  id: string;
  no: string;
  title: string;
  lead?: string;
  isAr: boolean;
}

const toArabicDigits = (s: string) => s.replace(/\d/g, (d) => '٠١٢٣٤٥٦٧٨٩'[Number(d)]);

export const SectionHead: React.FC<SectionHeadProps> = ({ id, no, title, lead, isAr }) => (
  <header className="mb-12 sm:mb-16">
    <Reveal>
      <div className="flex items-center gap-4 sm:gap-5">
        <span
          aria-hidden="true"
          className="mb-4 grid h-12 w-12 shrink-0 place-items-center rounded-full border border-gold/70 text-lg font-light leading-none text-ink sm:h-14 sm:w-14 sm:text-xl"
        >
          <span className="block -translate-x-[0.05em] translate-y-[0.13em]">{isAr ? toArabicDigits(no) : no}</span>
        </span>

        <div className="relative pb-4">
          <h2 id={id} className="display-title">
            {title}
          </h2>
          <GoldRule isAr={isAr} className="absolute inset-x-0 bottom-0 w-full" />
        </div>
      </div>
    </Reveal>

    {lead && (
      <Reveal delay={0.1}>
        <p className="lead mt-6 max-w-2xl">{lead}</p>
      </Reveal>
    )}
  </header>
);
```

---

## الفحص

1. `npm run lint` ثم `npm run build`.
2. أجب بـ "نعم" أو "لا": الدائرة بجانب العنوان في نفس السطر، والخط الذهبي تحت العنوان مباشرة وبعرضه، والرقم داخل `<span>` داخلي عليه الإزاحة.
3. تقرير من ثلاثة أسطر كحد أقصى.
